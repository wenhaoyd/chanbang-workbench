# 象邦工作台 (Chanbang Workbench)

个人/律所综合工作管理平台 —— 工作计划、灵感记录、案件管理、证件业务、材料库。

## 功能
- 🔐 登录认证（用户名 + 密码，localStorage 持久化）
- 📊 工作概览仪表盘
- 📋 工作计划（进行中 / 已完成、待办提醒）
- 💡 灵感记录
- ⚖️ 律所案件 / 📄 证件业务 / 📁 其他业务
- 📚 业务材料库（15 个预置模板）

## 技术栈
纯静态前端（HTML/CSS/JS），数据存于浏览器 localStorage。无后端依赖，可直接托管于 GitHub Pages / 任意静态服务器。

## 部署
将本目录内容推送到 GitHub 仓库，在仓库 Settings → Pages 选择 `main` 分支根目录即可。
